Football TV Test - Android TV

This is a minimal test project:
- TV-friendly launcher
- one test football match
- WATCH button
- Media3/ExoPlayer video playback
- BACK TO MATCH button

The bundled test URL is a public sample video and is only used to verify the player.

Build requirements:
- Android Studio with Android SDK
- Android Gradle Plugin 8.6.1
- JDK 17 or newer

Open this folder in Android Studio and Build > Build APK(s).
